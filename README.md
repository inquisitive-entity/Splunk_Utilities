# Splunk_Utilities
Useful splunk searches, a combination of searches, dashboards, kvstores I wish I had while learning a using splunk.

License Usage
- License Limit
- Avg Daily usage
- Day of week Daily usage
- Min/Max/Median/Mode/Days exceeded limit
- monthly trend
- Top 10 indexes/sourcetypes
- Deltas: which source ingest has changed a lot recently

Datasources
- kvstore that has index, sourcetype, latestLog
- tstats search equivalent (-24h)
- mapping sourcetypes to data type (firewall, edr, etc)
- *too_small

Logs Gone Bad
- uses frequency analysis to determine if a source has silently dropped or if the volume has gone way down
